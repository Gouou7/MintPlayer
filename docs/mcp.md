# MCP 播放控制

[English](mcp.en.md) | 简体中文

Mint Player 可选择性开启本机 MCP 服务，让本机的 MCP 客户端（例如 Agent）搜索资料库，并控制播放与待播队列。服务默认关闭，仅监听回环地址 `127.0.0.1`。

## 开启服务

1. 打开设置中的「MCP」分区。
2. 打开服务开关「启用 MCP」。
3. 保持 Mint Player 运行，把设置页显示的地址填入本机 MCP 客户端。

关闭服务开关或退出 App 后，该地址立即失效。

## 访问令牌

默认要求访问令牌：点「复制令牌」取得令牌，在客户端中配置 `Authorization: Bearer <令牌>` 请求头。关闭「要求访问令牌」后，本机任意进程都可以控制播放，且无需请求头。

令牌保存在当前用户的 App 专用目录中，不访问钥匙串：目录权限为 `0700`，令牌文件权限为 `0600`。同一系统用户运行的进程仍可能读取该文件。

从使用钥匙串存储令牌的旧版本升级后，需要重新复制令牌并更新 MCP 客户端；重新生成令牌后同理。

## 端口

默认端口为 Release `49431`、Debug `49432`，可在设置中修改，取值范围 1024–65535，修改后会重启服务。端口被占用时，设置页会显示启动失败原因，可修改端口后重试。

## 可用工具

| 能力 | 工具行为 |
| --- | --- |
| 搜索 | 搜索歌曲、艺人及专辑 |
| 播放 | 播放单首歌曲，或按顺序、随机播放指定艺人或专辑 |
| 读取 | 读取当前歌曲的完整歌词、播放状态与待播队列 |
| 控制 | 播放、暂停、上一首、下一首、音量、进度 |
| 队列 | 加入待播，以及移除、移动、清空和撤销清空待播队列 |

歌曲通过资料库 UUID 选择，艺人与专辑通过搜索结果中的 ID 选择。工具结果不包含本地音频路径。
