# MCP 开发技能

这里收录了 Anthropic 官方 Claude 插件仓库中 `mcp-server-dev` 插件的三项技能。[上游源码](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev)

- `build-mcp-server` 用于设计和搭建 MCP 服务器。[技能说明](build-mcp-server/SKILL.md)
- `build-mcp-app` 用于为 MCP 应用添加交互界面。[技能说明](build-mcp-app/SKILL.md)
- `build-mcpb` 用于将本地 MCP 服务器及其运行时打包为 MCPB。[技能说明](build-mcpb/SKILL.md)
